# Design-Unterlagen

`explorations/` enthält die ursprünglichen visuellen Richtungen und Prompts. `mockup/` enthält den frühen klickbaren Prototyp. Beide sind historische Entwurfsunterlagen; die aktuellen App-Oberflächen liegen unter `apps/`.

Verbindliche Designentscheidungen und plattformspezifische Umsetzung stehen in den DESIGN.md-Dateien der Apps.
