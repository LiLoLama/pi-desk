# Pi Desk · Quiet Studio Dark

`index.html` direkt im Browser öffnen. Kein Build, keine Installation, keine externen Abhängigkeiten.

Klickbar: Projekte und Aufgaben, neue Demo-Aufgabe, Suche (⌘K), Vorschau/Diff/Dateien, Agentendetails, Modellprofile, Kontext-Mehrfachauswahl am Composer, entfernbare Kontext-Chips, Genehmigungsprofile (Nachfragen/Projektzugriff/Vollzugriff), Abstände, Seitenleisten und ein kompletter Demo-Buchungsablauf. Nachrichten erhalten eine lokale simulierte Antwort; Stoppen ist möglich. Der Verlauf kann als JSON exportiert werden.

Alle Inhalte sind Beispieldaten. Es gibt keine Agenten-, Git-, Modell- oder Netzwerkanbindung. Eingaben bleiben im Arbeitsspeicher der Seite und verschwinden beim Neuladen; nur ein expliziter Export erzeugt eine Datei. Buchungsdaten werden nicht versendet.

Die verbindlichen Designentscheidungen stehen in DESIGN.md. Besonders: keine verschachtelten Karten, möglichst keine Container, Icons für Aktionen und Text für Inhalte.

Eigene Nachrichten erscheinen rechts in dezenten Blasen; der Agent antwortet links ohne Rollenlabels. Genehmigungsprofile ändern keine echten Berechtigungen.
