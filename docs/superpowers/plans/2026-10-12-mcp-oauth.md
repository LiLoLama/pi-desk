# OAuth-Anmeldung für MCP-Server – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** HTTP- und SSE-MCP-Server mit OAuth (wie der AITI-MCP) lassen sich in Pi Desk per Browser anmelden; OMP nutzt und erneuert die Anmeldung danach selbst.

**Architecture:** Je App führt die lokale Node-Engine die Anmeldung aus (`mcp-oauth.mjs`: Discovery, Registrierung, PKCE, Loopback-Rückleitung, Token-Tausch) und legt das Ergebnis im Format von OMP 18.4.10 in `<Daten>/agent/agent.db` ab (`mcp-credentials.mjs`). `capabilities.mjs` verbindet beides mit der Serverliste, dem Verbindungstest und der mcp-remote-Umstellung; `server.mjs` stellt Routen bereit und startet OMP-Prozesse nach einer Anmeldung neu (ruhende sofort, laufende nach Ende der Aufgabe). Die Oberflächen (SwiftUI, Electron) zeigen Status, Knöpfe, Anmeldehinweis und „Erweiterte Anmeldung“.

**Tech Stack:** Node ≥ 24 (`node:sqlite`, `node:http`, `fetch`), `node:test`, OMP 18.4.10, SwiftUI/AppKit, Electron 44.

**Spec:** [2026-10-12-mcp-oauth-design.md](../specs/2026-10-12-mcp-oauth-design.md)

## Global Constraints

- Plattformen getrennt: Jede App bekommt eigene Kopien von `mcp-oauth.mjs`, `mcp-credentials.mjs` und Testdateien; kein gemeinsames Modul (AGENTS.md). Inhalt darf identisch sein.
- Deutsch in UI, Fehlermeldungen und Doku, echte Umlaute. Codekommentare englisch und knapp.
- Code-Stil wie im Bestand: `.mjs` kompakt mit Einzeilern; Swift wie `Capabilities.swift`.
- Quiet Studio Dark beibehalten; vorhandene Komponenten und Klassen nutzen.
- Speicher: Tabelle `auth_credentials`, Schema-Version **8** (`auth_schema_version.version`), Schlüssel `mcp_oauth:profile:${process.env.OMP_PROFILE||'default'}:${url}`, `credential_type='oauth'`, `data` = JSON `{access, refresh, expires, tokenUrl, clientId, clientSecret?, resource?, authorizationUrl}`. Bei abweichendem Schema: Fehler „Diese OMP-Version speichert Anmeldungen anders. Bitte Pi Desk aktualisieren.“
- Rückleitung: nur `127.0.0.1`, Pfad `/callback`, Port aus „Erweiterte Anmeldung“ oder zufällig. Gesamtzeit 5 min, Metadaten-/Registrierungs-/Token-Anfragen je 10 s.
- Registrierung: `{client_name:"Pi Desk", redirect_uris:[redirect_uri], grant_types:["authorization_code","refresh_token"], response_types:["code"], token_endpoint_auth_method:"none", application_type:"native", scope?}`.
- Fehlermeldungen wörtlich aus Spec Abschnitt 1, Tabelle „Fehlermeldungen“.
- `npm test` darf keine OMP-Runtime brauchen (der Windows-Workflow testet vor dem Laden der Runtime). Tests mit echter OMP liegen in `test/mcp-oauth-smoke.mjs` und laufen von Hand.
- **Commits nur mit Freigabe von Liam.** Commit-Nachrichten deutsch, Ende `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Kein Push, kein Release.

// OMP 18.4.10 has no non-TUI entry point for this; it uses and refreshes the stored result itself.
import http from 'node:http';import {createHash,randomBytes} from 'node:crypto';
const REQUEST_TIMEOUT=10000,LOGIN_TIMEOUT=300000;
export class OAuthError extends Error{}
const fail=message=>{throw new OAuthError(message);};
const trim=u=>String(u).replace(/\/+$/,'');
const NO_SERVER='Der Server nennt keinen gültigen Anmeldeserver.',NEEDS_APP='Dieser Server verlangt eine registrierte App. Trage unter ‚Erweiterte Anmeldung‘ eine Client-ID ein.';

export async function discover(url,ch,fetchFn){

 let prm=null;for(const candidate of new Set([ch.resourceMetadata,`${u.origin}/.well-known/oauth-protected-resource${p}`,`${u.origin}/.well-known/oauth-protected-resource`].filter(Boolean))){prm=await getJSON(fetchFn,candidate);if(prm)break;}

 if(typeof meta?.authorization_endpoint!=='string'||typeof meta?.token_endpoint!=='string')fail(NO_SERVER);
 if(Array.isArray(meta.code_challenge_methods_supported)&&!meta.code_challenge_methods_supported.includes('S256'))fail('Der Anmeldeserver unterstützt kein PKCE mit S256.');

}

}
export function authorizeUrl(endpoint,{clientId,redirectUri,challenge,state,scope,resource}){
