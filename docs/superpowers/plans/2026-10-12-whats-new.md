# „Neu in dieser Version“ nach Updates – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pi Desk zeigt nach einem Update, bei dem sich Haupt- oder Mittelnummer erhöht hat, beim ersten Start einmal die Neuerungen aus der mitgelieferten `CHANGELOG.md`. Über „Was ist neu“ ist der Changelog jederzeit abrufbar.

**Architecture:** Je Plattform eine reine, getestete Regel `whatsNew(changelog, seen, installed)` und ein eigenes Fenster bzw. ein eigener Dialog. Windows: die Regel liegt in `desktop/changelog.cjs`, der Hauptprozess merkt sich `seenVersion` in `updates.json`, die Oberfläche holt das Ergebnis per IPC ab. macOS: die Regel liegt in `native/UpdateLogic.swift`, ein neues `native/WhatsNew.swift` merkt sich die Version in `UserDefaults` und zeigt ein SwiftUI-Fenster. Update-Dialoge warten, bis das Fenster geschlossen ist.

**Tech Stack:** Windows: Electron 44, Node `node:test`, `marked` + DOMPurify. macOS: SwiftUI/AppKit, Sparkle 2.10.0, `swiftc`, Node `node:test`.

**Spec:** [2026-10-12-whats-new-design.md](../specs/2026-10-12-whats-new-design.md)

## Global Constraints

- Plattformen getrennt umsetzen und prüfen, kein gemeinsames Modul (AGENTS.md). macOS-Tests beweisen keinen Windows-Lauf.
- Deutsch in UI und Doku, echte Umlaute. Codekommentare englisch und knapp wie im Bestand.
- Quiet Studio Dark beibehalten. Windows: vorhandene Klassen `connect-dialog update-dialog`, `dialog-head`, `update-notes`, `form-actions`, `update-spacer`, `primary`. macOS: Stil von `UpdateView` (Hintergrund `Color(red: 0.105, green: 0.114, blue: 0.118)`, Tint `Color(red: 0.73, green: 0.81, blue: 0.72)`, 520 pt breit, `ChatMarkdown`).
- Code-Stil wie im Bestand: Windows kompakt mit Einzeilern; Swift wie `Updates.swift`.
- Regel (wörtlich aus der Spec): Fenster nur, wenn eine gültige gespeicherte Version existiert, `installed > seen` gilt, sich `major.minor` unterscheidet und mindestens ein Abschnitt mit `seen < Version ≤ installed` existiert. `remember` ist immer `installed` und wird gespeichert, bevor das Fenster erscheint.
- Speicherorte: macOS `UserDefaults`-Schlüssel `whatsNew.seenVersion`. Windows Feld `seenVersion` in `<Profil>/desktop/updates.json`.
- Fehlt die `CHANGELOG.md` oder ist sie unlesbar: kein Fenster, nichts speichern. „Was ist neu“ zeigt dann „Keine Änderungsnotizen.“
- „Was ist neu“ zeigt die letzten zehn Abschnitte bis zur installierten Version und ändert die gespeicherte Version nicht.
- Fenstertitel: „Neu in Pi Desk X.Y“ beim automatischen Fenster, „Was ist neu in Pi Desk“ beim manuellen Aufruf. Knopf „Verstanden“; Esc schließt.
- Links im Changelog öffnen nur `http`/`https`.
- **Commits nur mit ausdrücklicher Freigabe von Liam.** Die Commit-Schritte werden ausgeführt, sobald Liam Commits für diese Umsetzung freigegeben hat; sonst bleiben die Änderungen ungestaged. Commit-Nachrichten auf Deutsch, Ende `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Kein Push, kein Release.

## Review Focus

- **CRLF-Zeilenenden in `CHANGELOG.md`** (Git mit `autocrlf` unter Windows, Editor unter Windows) → Abschnitte werden trotzdem erkannt. Test in Task 1 (Windows) und Task 4 (Swift).
- **Zweistellige Versionsteile** (0.9.3 → 0.10.0) → numerischer Vergleich, Fenster erscheint. Test in Task 1 und Task 4.
- **Überschrift mit Bindestrich statt Halbgeviertstrich oder ohne Datum** (`## 0.4.1 - 12.10.2026`, `## 0.4.0`) → Abschnitt wird erkannt, die Anzeige nutzt einheitlich „ – “. Test in Task 1 und Task 4.
- **Kaputter oder fremder gespeicherter Wert** (`""`, `"0.4"`, `"0.4.0-beta"`, `"kaputt"`) → wie „keine gespeicherte Version“: kein Fenster, installierte Version merken. Test in Task 1 und Task 4.
- **Update-Prüfung findet eine Version, während das Fenster offen ist** → Update-Dialog erscheint erst nach „Verstanden“, nur mit dem letzten Stand. Von Hand in Task 3 und Task 5, weil die Dialogsteuerung keine Testumgebung hat.

// "Neu in dieser Version": shown once when major or minor grew since the last seen version; remember is saved before showing.
function whatsNew(text,seen,installed){
 const quiet={show:false,notes:'',remember:installed};
 if(typeof seen!=='string'||!VERSION.test(seen)||compareVersions(installed,seen)<=0||minorOf(installed)===minorOf(seen))return quiet;

```swift

  struct ChangelogEntry: Equatable {
    let version: String
    let date: String
    let body: String
  }

  /// CHANGELOG.md sections "## X.Y.Z – DD.MM.YYYY", same format as scripts/changelog.mjs.
  static func parseChangelog(_ text: String) -> [ChangelogEntry] {
    let heading = try! NSRegularExpression(pattern: #"^## (\d+\.\d+\.\d+)(?:\s+[–—-]\s+(.+?))?\s*$"#)
    var entries: [(version: String, date: String, lines: [String])] = []
    for line in text.replacingOccurrences(of: "\r\n", with: "\n").components(separatedBy: "\n") {
      let range = NSRange(line.startIndex..., in: line)
      if let match = heading.firstMatch(in: line, range: range), let version = Range(match.range(at: 1), in: line) {
        let date = Range(match.range(at: 2), in: line).map { String(line[$0]) } ?? ""
        entries.append((String(line[version]), date, []))
      } else if !entries.isEmpty {
        entries[entries.count - 1].lines.append(line)
      }
    }
    return entries.map {
      ChangelogEntry(
        version: $0.version, date: $0.date,
        body: $0.lines.joined(separator: "\n").trimmingCharacters(in: .whitespacesAndNewlines))
    }
  }

  static func render(_ entries: [ChangelogEntry]) -> String {
    entries.map { "## \($0.version)\($0.date.isEmpty ? "" : " – \($0.date)")\n\n\($0.body)" }
      .joined(separator: "\n\n")
  }

  static func isVersion(_ value: String?) -> Bool {
    guard let value else { return false }
    let parts = value.split(separator: ".", omittingEmptySubsequences: false)
    return parts.count == 3
      && parts.allSatisfy { part in !part.isEmpty && part.allSatisfy { $0.isASCII && $0.isNumber } }
  }

  private static func minor(_ version: String) -> String {
    version.split(separator: ".").prefix(2).joined(separator: ".")
  }

  /// "Neu in dieser Version": shown once when major or minor grew since the last seen version.
  /// `remember` is always the installed version and is saved before the window appears.
  static func whatsNew(changelog: String, seen: String?, installed: String) -> (
    show: Bool, notes: String, remember: String
  ) {
    guard let seen, isVersion(seen), compare(installed, seen) > 0, minor(installed) != minor(seen) else {
      return (false, "", installed)
    }
    let entries = parseChangelog(changelog)
      .filter { compare($0.version, seen) > 0 && compare($0.version, installed) <= 0 }
      .sorted { compare($0.version, $1.version) > 0 }
    return (!entries.isEmpty, render(entries), installed)
  }

  /// "Was ist neu": the latest sections up to the installed version.
  static func recentNotes(changelog: String, installed: String, limit: Int = 10) -> String {
    render(
      Array(
        parseChangelog(changelog).filter { compare($0.version, installed) <= 0 }
          .sorted { compare($0.version, $1.version) > 0 }.prefix(limit)))
  }
```

import AppKit
import SwiftUI

/// "Neu in dieser Version": once after an update that raised major or minor, and on request.
@MainActor final class WhatsNew: NSObject, NSWindowDelegate {
  static let shared = WhatsNew()
  static let seenKey = "whatsNew.seenVersion"

  private var window: NSWindow?
  private var afterClose: [() -> Void] = []

  var isOpen: Bool { window?.isVisible == true }

  /// Runs at launch, before the first automatic update check.
  func showIfNeeded() {
    guard let text = Self.changelog() else { return }
    let installed = AppUpdates.shared.installedVersion
    let result = UpdateLogic.whatsNew(
      changelog: text, seen: UserDefaults.standard.string(forKey: Self.seenKey), installed: installed)
    // Saved before showing: a crash with the window open must not bring it back on every launch.
    UserDefaults.standard.set(result.remember, forKey: Self.seenKey)
    if result.show { present(title: "Neu in Pi Desk \(Self.minor(installed))", notes: result.notes) }
  }

  /// Menu and settings: latest sections up to the installed version; the seen version stays as it is.
  func showAll() {
    let notes =
      Self.changelog().map {
        UpdateLogic.recentNotes(changelog: $0, installed: AppUpdates.shared.installedVersion)
      } ?? ""
    present(title: "Was ist neu in Pi Desk", notes: notes.isEmpty ? "Keine Änderungsnotizen." : notes)
  }

  /// Update dialogs wait until this window is closed.
  func whenClosed(_ action: @escaping () -> Void) {
    if isOpen { afterClose.append(action) } else { action() }
  }

  func close() { window?.close() }

  private func present(title: String, notes: String) {
    let view = WhatsNewView(title: title, notes: notes) { [weak self] in self?.close() }
    if let window {
      window.contentViewController = NSHostingController(rootView: view)
    } else {
      let window = NSWindow(contentViewController: NSHostingController(rootView: view))
      window.title = "Neu in Pi Desk"
      window.styleMask = [.titled, .closable]
      window.isReleasedWhenClosed = false
      window.appearance = NSAppearance(named: .darkAqua)
      window.delegate = self
      self.window = window
    }
    window?.center()
    window?.makeKeyAndOrderFront(nil)
    NSApp.activate(ignoringOtherApps: true)
  }

  nonisolated func windowWillClose(_ notification: Notification) {
    MainActor.assumeIsolated {
      let pending = afterClose
      afterClose = []
      // After the close finished, so isOpen is already false for the waiting dialogs.
      DispatchQueue.main.async { pending.forEach { $0() } }
    }
  }

  static func changelog() -> String? {
    Bundle.main.url(forResource: "CHANGELOG", withExtension: "md")
      .flatMap { try? String(contentsOf: $0, encoding: .utf8) }
  }

  private static func minor(_ version: String) -> String {
    version.split(separator: ".").prefix(2).joined(separator: ".")
  }
}

private struct WhatsNewView: View {
  let title: String
  let notes: String
  let close: () -> Void
  private let tint = Color(red: 0.73, green: 0.81, blue: 0.72)

  var body: some View {
    VStack(alignment: .leading, spacing: 14) {
      Text(title).font(.system(size: 18, weight: .semibold))
      ScrollView {
        ChatMarkdown(
          text: notes, fontSize: 13, onOpenFile: { _ in }, onRevealFile: { _ in },
          onOpenURL: { value in
            if let url = URL(string: value), ["https", "http"].contains(url.scheme ?? "") {
              NSWorkspace.shared.open(url)
            }
          }
        ).frame(maxWidth: .infinity, alignment: .leading).padding(12)
      }.frame(minHeight: 160, maxHeight: 360)
        .background(Color.white.opacity(0.03), in: RoundedRectangle(cornerRadius: 8))
      HStack {
        Spacer()
        Button("Verstanden", action: close).keyboardShortcut(.defaultAction)
      }
    }.padding(24).frame(width: 520, alignment: .leading)
      .background(Color(red: 0.105, green: 0.114, blue: 0.118)).preferredColorScheme(.dark).tint(tint)
      .onExitCommand(perform: close)
  }
}
